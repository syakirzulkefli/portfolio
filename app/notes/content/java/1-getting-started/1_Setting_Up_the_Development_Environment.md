# 1. Setting Up Development Environment

- Download and install the necessary tools to build
  Java applications.
- So _open_ up browser and search for `JDK download`.
- JDK stands for Java development kit and it's basically a `software development environment`
  for building Java applications.
- It has a
  i. compiler,
  ii. it has a bunch of code that we can reuse,
  iii. it has a Java runtime environment
  iv. and a bunch of other stuff.
- So on page Oracle.com, choose Java SE, which is short for Java standard
  edition.
- Follow all the installation until completes.
- Next piece of software we need is a code editor.
- There are so many code editors for building Java applications.
- The popular ones are netbeans, eclipse, and intelligent.
- In this case i would rather use vscode.

```java

// this is comments
public class Main{
    public static void main (String[] args) {
        System.out.print("Hello World!");
    }
}

// output would be Hello World!
```
