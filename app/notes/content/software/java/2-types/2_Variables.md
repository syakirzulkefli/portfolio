# **Variables**

We use variables to temporarily store data in computer's memory.

For example we want to store someone's age in the memory.
So we declare a variable like this.
int age equals 30.

```java
int age = 30;
```
So int or integer is the type of this variable.
This variable we can only store integers which are whole numbers.
Like 1, 2, 3, 4, numbers that don't have a decimal point.

1. First we specify the type of variable.
2. Then we give it a name or a label. This is also called an identifier. Because we use it to identify our variable.
3. The equals sign is called the assignment operator. And 30 is the initial value that we are assigning to this variable.

We're initializing this variable which means we're giving it an initial value.
We always have to initialize our variables before reading them.

So with this line, we're storing number 30 somewhere in computer's memory.
And we're assigning this label to that memory location.

We can also change the value of our variable.
So after we initialize it.
We can change it to 35.

Now when we run this program again.
We see 35.

We can also initialize multiple variables on the same line.
But this is something that not recommended because it makes our code ugly and hard to read.

We can also copy the value of one variable into another.

Let me delete these variables.
And declare another variable like temperature and set it to 20.
So using a comma we can declare multiple variables on the same line.
Now even though this is technically possible.
It's not something that is recommended.

So it's always better to declare one variable on each line like this.

We can also copy the value of one variable into another.

We can declare a new variable called my age.
We set it to 30.
And then we declare another variable like her age.
And we set it to my age.

We're going to see 30.

So we're copying the value of this variable into this other variable.
