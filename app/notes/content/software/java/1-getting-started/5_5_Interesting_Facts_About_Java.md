#  **5 Interesting Facts About Java**

1. Java was developed by James Gosling in 1995 at Sun Microsystems, which was later acquired
by Oracle in 2010. It was originally called Oak after an oak tree that stood outside
Gosling's office. Later it was renamed to Green and was finally renamed to Java, inspired
by Java Coffee. That's why it's logo looks like a cup of coffee.

2. Have 4 editions of Java for building different kinds of applications:-
 - **_Java standard edition_**. This is the core Java platform. It contains
all of the libraries that every Java developer must learn. 
 - **_Java enterprise edition_**, which is used for building very large scale and distributed systems. It's built
on top of Java standard edition and provides additional libraries for building fault
tolerant, distributed, multi-tier software. 
 - **_Java micro edition_**, which is a subset of Java standard edition designed for mobile devices. So it has libraries, specific
to mobile devices. 
 - **_Java card_**, which is used in smart cards. The latest version of Java is Java standard edition 12, which was released just a few months ago in March 2019. 
 
3. Java has closed to 9 million developers worldwide. 

4. Currently about 3 billions mobile phones run Java as well as 120 millions TV sets and every blue ray player. 

5. According to indeed.com, the average salary of a Java developer is just over $100,000 per year in
the US. So as we can see, Java is everywhere, which means more opportunities to get hired as a professional Java programmer.

*data as of 2019
