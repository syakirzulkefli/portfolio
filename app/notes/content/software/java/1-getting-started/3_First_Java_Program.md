# **First Java Program**

- Double slash `//` is for comments.

- For now, just remember that the main method in our program should always be static. Example given public `static` void.

- void means this method is not going to return any value.

```java
package dev.syakir;

public class Main {
    public static void main (String [] args) {
        System.out.println("Hello World");
    }
}

will be printed Hello World on the terminal.
```
